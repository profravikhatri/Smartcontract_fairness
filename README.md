
# Ethereum Integrated Smart Contract Optimizer

This repository implements a multi-objective optimization framework for:

- Gas efficiency (G)
- Vulnerability exposure (V)
- Role-based fairness variance (F)

Environment:
- Solidity 0.8.20
- Hardhat
- Python (Pandas)

To run:
1. npm install
2. npx hardhat compile
3. npx hardhat run scripts/deploy.js
